# Cybertron loop

> **Status:** Spec only. Loop wording agreed in chat; no crawler code.

A 9-block crawler loop written in Joshua's words: One has a target, Two has the page, Three have the links, Four would check (lit or dark), Five records, Six reports, Seven rests, the 8th block has its state, Repeat is its own block.

## Where this came from

This idea came up in a chat with one of Joshua Almeida's bots (Cybertron bot, Oct 19 2026) and was not taken further at the time. This repo records it so it can be picked up later.
